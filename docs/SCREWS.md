# 螺丝扣

当前工程只玩螺丝。圆环、胶囊棍和衔接已经不在工程里。电脑上的关卡编辑在 `editor.html`，规则在 [EDITOR.md](./EDITOR.md)。外形尺寸在 [PARTS.md](./PARTS.md)。

## 模块

| 模块 | 职责 |
|---|---|
| `parts.ts` | 网格和尺寸。中心线是 `screwSpans`。头和扣的俯视外框是 `headSilhouette`、`nutSilhouette` |
| `screws.ts` | 扣和螺丝怎么滑、什么时候挡住、轮廓距离、什么时候算离开卡扣。松手补到出口是 `releaseSlack` |
| `play.ts` | 按下、拖动、松手、把整关放进顶栏和底栏之间。不写阻挡、离场、点选、补量、闪光、描边或夸奖公式 |
| `camera.ts` | 设计坐标和世界坐标。视口高 10。缩放固定为 `STAGE_ZOOM`，不按关卡内容重取景 |
| `fall.ts` | 离场：重力、扣的转轴、层级、出屏销毁 |
| `intent.ts` | 点选和松手补量。点选是 `pressAim` / `moveAim`。补量是 `releaseFlick` / `releasePad`。轮廓仍在 `screws.ts` |
| `feedback.ts` | 挡住的那件闪一次。准备离场时慢慢变亮。正在拖的件不闪 |
| `praise.ts` | 离场夸奖字、连击和这一档的分数。见「夸奖」 |
| `outline.ts` | 选中件的同色屏幕描边。按下立刻全亮，松手后淡出 |
| `hapticFeel.ts` | 齿轮里的震动数值，存在本机 |
| `hapticsPlay.ts` | 一次拖动一条震动会话。`play.ts` 只调用 `playHaptics` |
| `palette.ts` | 螺丝和扣的六色，以及一关里怎么挑下一种颜色 |
| `levelio.ts` | 读 `public/levels/`。顺序在 `order.json`。没有扣的数据时按布局生成 |
| `editor.html` | 电脑上摆关卡。点保存才写入。不在这里试玩 |

`play.ts` 不写阻挡、离场、意图、闪光、描边、夸奖或震动公式。`screws.ts` 不建网格。改规则时改对应模块，并改这一页。

## 手感尺度

接触外形和手感距离分开。拖动、落位、圆头和弯用网格外框，定义在 `screws.ts`。下面的比例只决定手指要滑多远，不改这些外框。比例是设计宽度，经当前缩放换成世界距离。

| 常量 | 值 | 规则 |
|---|---|---|
| `INTENT_FINGER` | 18 设计像素 | 按下和还没选中时，真实轮廓外这一圈里的件才进入候选 |
| `INTENT_CLEAR` | 8 设计像素 | 候选有两件以上、点还不在轮廓里时，沿滑轴滑过这么远才用趋势选一件 |
| `INTENT_AXIS` | 1.5 | 胜出的轴投影至少是另一轴的这些倍。这条轴上只能有一件 |
| `INTENT_PARALLEL` | 0.35 | 两轴叉积绝对值小于此值，当作平行。平行的几件趋势分不出谁 |
| `INTENT_NEAR` | 4 设计像素 | 领先轴上有多件、轮廓距离差在这一带宽里，才用「解得开」打破平局。更远的差仍选近的。这个宽度是螺丝自己的数 |
| `RELEASE_WINDOW_MS` | 100 毫秒 | 松手只读这段里的沿杆位移。更早的回头不计入 |
| `INTENT_SLEEVE` | 5% | 这段沿杆慢于 250 设计像素/秒时，向前看的上限 |
| `INTENT_FLICK` | 20% | 这段达到 250 设计像素/秒时的上限。再快也不加大。套在长卡扣里时常常不够一次脱离 |
| `INTENT_FLICK_SPEED` | 250 | 设计像素/秒。世界速度乘当前缩放，再换成设计像素 |
| `HIT_REARM` | 0.03 世界单位 | 离开接触这么远之后，挡住的那件才能再闪一次 |

## 零件

一根螺丝有若干直段。直段一头是出口，另一头是死头。直螺丝的死头是八边头。L 和 U 的死头是弯。螺丝扣只在直段上，不能绕过弯。

要亲手拖开的零件用关卡颜色：螺丝（头和杆）和螺丝扣。银卡扣解开后自己掉，颜色保持 `#c8c7c5`。配色规则见下一节。

银卡扣钉在世界里。关卡没写 `buckleT` 时，卡扣套在死头一侧：沿杆二分，停在弯折部分刚要碰到卡扣银边的地方。直螺丝没有弯，停在八边头刚要碰到的地方。写了 `edges` 和 `buckleT` 的关卡，卡扣位置用文件里的距离。`null` 表示这条边没有卡扣。U 的底边不放卡扣。螺丝顺着还留着卡扣的那条直边滑，孔的方向和这条边一致。卡扣不跟着杆走。整根螺丝离开后，卡扣跟着掉。

## 颜色

色值以 `src/game/palette.ts` 为准。舞台背景写在 `main.ts` 和 `style.css` 的 `--stage-bg`，两边同为 `#f6f1e8`。改颜色时改这些地方，并改这一节。

| 用途 | 色值 |
|---|---|
| 舞台 | `#f6f1e8` |
| 银卡扣 | `#c8c7c5`。不跟关卡色。软影在 `parts.ts`，`rgba(70, 52, 36, 0.38)` |
| 蓝、绿、红、橙、紫、黄 | `#3aa8ff`、`#3dcc73`、`#ff564c`、`#ff8a2a`、`#a86bff`、`#f2c14e` |

同一关里自动上色：

- 新螺丝用本关螺丝里出现最少的颜色。次数相同，按上表从左到右。
- 扣不用自己这根螺丝的颜色，用本关扣里出现最少的其余颜色。一根杆上的扣因此错开。
- 没写扣的关卡，生成扣时用同一条规则。
- 编辑器里先点色板再放，或选中后再点色板，用点中的颜色，不走自动。

结算卡片不跟舞台色，仍是 `style.css` 里 `.result` 的米色卡片和橙色按钮。

## 螺丝扣

两个方向都沿杆跟手。

- 同一段上的其他扣、死头、弯、任何银卡扣、别的螺丝，都会挡住。
- 扣的后缘完全越过杆头的圆头，才离开杆。离开之后仍只能沿这根轴移动，不能离开轴线。松手才下落。
- 松手后的下落见下一节「离场」。扣在离场时就带上翻转。已经离开杆、手指还按着时，扣慢慢变亮。
- 绕杆的转角按螺纹走。每两圈螺纹转过八边扣的一个边。

## 螺丝

按住杆或卡扣，沿卡扣方向拖。拖的时候不掉。指针每次只把新的位移投影到滑轴上，交给 `dragScrew`。选中哪一件见「点选」。撞上谁见「阻挡闪亮」。松手补不补见「松手补脱离」。

螺丝已经离开自己的卡扣、手指还按着时，螺丝和卡扣慢慢变亮，松手才掉。

接触、落位和点选都读同一条 `screwSpans`。

阻挡：

- 直段和弯都是半径 `SHAFT_CORE` 的管子，和扫出来的网格一样粗。
- 直段管子是桶身，可以留在卡扣孔里。碰撞半径是螺纹齿顶 `SHAFT_RADIUS`。画出来的螺旋不参与阻挡。卡扣、头、扣的网格孔是齿顶加 `THREAD_HOLE_GAP`（0.008）。
- 只有弯出桶身、并且探出孔的金属才挡住自己的卡扣。卡扣沿杆二分，停在刚要碰上的位置。直螺丝没有弯，停在八边头刚要碰上的位置。
- 套筒和把手来自 `buckleShape`，圆角是 `barCorner`。
- 八边头和螺丝扣用网格的俯视外框。倒角把中心沿杆移了 `bevel`。扣的横宽随转动变化。
- 这根螺丝上的扣，内限用同一套接触：扣的外框刚要进卡扣就停。没有卡扣的直段仍用布局里的死头内限。
- 相贴允许。重叠超过 `0.001` 算挡住。滑动停在第一处接触，不整步退回。

## 阻挡闪亮

螺丝和螺丝扣共用这一条。闪亮的是挡住的那一件，不是正在拖的那一件。颜色用它自己的，强度 `0.42`，大约 `0.09` 秒，只闪一次。

- 刚滑过去撞上，并且这一下确实移动了：震一下，挡住的那件同时闪。
- 已经贴住，再往阻挡方向推而零件不动：只闪挡住的那件，不再震。
- 同一下只闪一次。贴着继续推不重复。离开接触大约 `HIT_REARM` 之后才能再闪。
- 挡住的可以是另一根螺丝、另一颗螺丝扣，或银卡扣。扣顶到这根杆上的银卡扣时，亮的是卡扣。这段没有银卡扣时，死头亮这根螺丝。
- 停住的位置往往还差一步才重叠。认人时沿推动方向探 `0.02`，认完放回。螺丝扣已经贴住邻居或死头再推，仍算挡住。

准备离场的慢慢变亮不是这一条。扣见「螺丝扣」，螺丝见上一节。

## 点选

一笔只选一件，选中后到松手不换。还没选中的位移不写入零件。选中后 `outline.ts` 沿这件网格立刻描一圈同色边，松手后淡出。描边不含银卡扣。银卡扣点选算在那根螺丝上。

按下时半径里没有件，这一笔不占操作。另一根手指可以开始点选或拖动。已经在盯住、分轴或拖动时，别的手指进不来。下落不锁操作。盘上已经没有螺丝和扣时，新的按下不再进玩法。

距离量到真实轮廓，轮廓内是 0。杆和弯按管子半径 `SHAFT_CORE`，圆头和螺丝扣按俯视外框，卡扣按套筒和把手的圆角条。挡住别的零件用同一套外框。候选是轮廓距离不超过 `INTENT_FINGER` 的件。半径只在按下和尚未选中时收集候选。扣不再单独放大。

- 按下时半径里没有件：这一笔留着，零件不动。半径里第一次只出现一件，先盯住它；点进入它的真实轮廓才选中。那一次采样已经在轮廓里，立刻选中。盯着时又进来第二件，改走下面的多件规则。从两件掉回一件，不因此选中。盯住的件离开半径，回到未盯住。
- 按下时半径里只有一件：立刻选中，点可以在金属外面。
- 按下时点在一件轮廓里：选它。点在螺丝杆上，而这根螺丝自己的扣也在半径里、滑轴又平行时，选离点最近的那颗扣。杆离这些扣都超过手指半径，才选螺丝。
- 多件、点还在缝里，按下面的顺序。前一条已经选出，就不再问下一条。
  1. 点进唯一轮廓，或杆上带着自己的扣：用上一条的轮廓规则。
  2. 沿滑轴滑过 `INTENT_CLEAR`，一条轴至少领先 `INTENT_AXIS`，并且这条轴上只有一件：选它。平行的几件过不了这一条。
  3. 滑过同样远，领先轴上仍有多件：轮廓比最近的那件远出 `INTENT_NEAR`，选最近的，不管解不解得开。距离差在这个带宽里，并且里面既有解得开的也有解不开的，选带宽里最近的那件解得开的。全都解得开，或全都解不开，继续等滑进轮廓。按下时位移还不够，不问这一条。

解得开只读现有出口，不读关卡答案，也不读刚才点过哪件。

- 螺丝还套在自己的卡扣里，并且至少一侧在 `INTENT_FLICK` 的向前看距离里出得去。已经不在卡扣里，或两侧在这个距离里都出不去，不算。
- 螺丝扣还没过圆头，并且沿杆还能往圆头那侧挪一截。已经离杆的不算。

## 松手补脱离

拖动中按真实接触停下，不算脱离。螺丝扣没有补量。

螺丝松手时只读 `RELEASE_WINDOW_MS` 里的沿杆位移。最后一点已经超出这个窗口、窗口里没有沿杆移动、或这段方向和这次拖动相反，不补。方向一致时，慢于 `INTENT_FLICK_SPEED` 的向前看上限是 `INTENT_SLEEVE`，达到则是 `INTENT_FLICK`。中途回头、收尾仍顺着拖动方向，仍按这段速度补。

`releaseSlack` 在这个上限里找离开自己卡扣的第一处，一次滑到刚过那一点。出口前面就有阻挡，不补，螺丝留在松手的位置。出口之后还有别的零件，不因此取消。20% 是上限：杆还在套筒里时，一次快拨常常到不了出口，还要再拖一次。

自己的螺丝扣、别的螺丝、别的螺丝扣、别的卡扣都会挡住这根螺丝。杆、头、弯和还套着的扣有一块还在自己的任一卡扣里，就还没脱离。全部离开之后，螺丝和卡扣进入「离场」，不翻转。还套在上面的扣用和单独拆下时一样的翻转。

## 离场

离开轨道之后由 `fall.ts` 负责。线速度从 0 开始，只受重力，每秒 `30`，方向是世界 −Y。不再沿出口给初速度。

螺丝扣在离场时定一根世界转轴，整段下落都绕这根轴，不拆成先绕 X 再绕 Y。轴以杆的朝外方向（死头指向开口）为底，左右随机偏最多 90°，再加一截横向随机。朝外的一侧先朝镜头（+Z）翻。初始转速大约每秒 2.4 到 4.8 弧度，下落中沿同一根轴大约每秒再加 5 到 10 弧度。

螺丝和银卡扣不翻转。

离场网格沿 +Z 抬到静止零件前面，距离是自身的旋转半径，后掉的再叠一层。正交相机不因 Z 改变大小。原点从左右或上方离开一整块屏幕，或从下方离开 `0.8`，才销毁网格。

## 夸奖

一次离场最多一句字。算一次离场的是：一根螺丝离开卡扣，或一颗螺丝扣被拖离杆。螺丝离场时还套着的扣跟着掉，那些扣不再各算一次。

这一关第一次离场不出字，也不加分。从第二次起，按顺序显示 Great!、Perfect、Excellent!、Amazing，到 Amazing 不再升高。分数跟显示的这一阶：200、300、400、500。顶栏用约 480 毫秒滚到新分数。

拖动里撞上或顶住，连击回到 0。下一次有字的离场再从 Great! 起。已经用过的第一次无字不会因为撞上再出现。换关后，新的第一次离场再次无字。

字的中心在手指抬起处上方 72 设计像素，用来躲开指尖。抬出舞台边缘仍用这一下的设计坐标。整句连同随后升起的 28 设计像素留在 390×844 内，左右再留 8 设计像素。上方放不下就改到抬起点下方 72 设计像素，动画改为下沉。

字挂在 `#ui-root`，盖过顶栏、底栏和齿轮面板。过关结算在它上面。出现时从 0.8 放到 1.08，再用约 240 毫秒收回 1。同时用 500 毫秒平移约 28 设计像素并略向一侧，后段淡出。放大结束不拆掉这句话，等这段移动结束。

## 镜头

正交相机从 +Z 看 XY。视口高度是 10 个世界单位，宽度按 390×844。进关时把螺丝外框放进顶栏和底栏之间，四周再留 24 个设计像素，并在还有空档时上移 48 像素。适配只用这块区域的 `FIT_FILL`（0.9），这就是画面上的正常大小。

## 过关

盘上没有螺丝、也没有螺丝扣时，松手弹出结算。
