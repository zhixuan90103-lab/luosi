# 螺丝扣

试玩里的直、L、U 螺丝。外形在 [PARTS.md](./PARTS.md)。拖动和阻挡只写在 `src/game/screws.ts`，`play.ts` 只负责按下、松手和离场。

## 零件

一根螺丝有若干直段。直段一头是出口，另一头是死头。直螺丝的死头是八边头。L 和 U 的死头是弯。螺丝扣只在直段上，不能绕过弯。

银卡扣固定在世界里，套在死头一侧，不放在螺丝扣通往出口的那段杆上。螺丝杆可以滑过自己的卡扣。卡扣不跟着杆走。

## 螺丝扣

两个方向都能沿杆拖。

- 同一段上的其他扣、死头、弯、任何银卡扣、别的螺丝，都会挡住。
- 扣的后缘完全越过杆头的圆头，才从杆上离开。
- 离开后沿出口飞出，并受重力下落。
- 绕杆的转角按螺纹走，每两圈螺纹转过八边扣的一个边。顶视时八边每 45° 外形就重复一次，整圈转会看起来比螺纹快。

## 螺丝

按住杆或卡扣，沿卡扣方向拖，和胶囊棍滑过套筒一样。

- 卡扣的套筒和把手用 `buckleMetrics`，长度再乘 `BUCKLE_LENGTH_SCALE`。网格和阻挡读这一份。
- 孔等于杆的直径。直杆可以留在孔里。弯管的圆面碰到套筒或把手的银边就停，底边不能穿进卡扣。
- 八边头和螺丝扣用沿杆的厚度（`screwCap`）去贴套筒端面。顶点半径只算横宽，不拿来当沿杆的阻挡。
- 自己的螺丝扣、别的螺丝、别的螺丝扣、别的卡扣，都会挡住这根螺丝。
- 拖的时候不掉。松手时，杆、头、弯和还套着的扣只要有一块还在任一卡扣的套筒里，就停在松手的位置。
- 全部离开所有自己的卡扣之后，松手，螺丝、上面的扣和这些卡扣一起受重力下落。

## 曾经的偏差

这些是重构前叠出来的行为，不再单独打补丁。

| 现象 | 原因 | 现在的规则 |
|---|---|---|
| 扣一到杆头中心就掉 | 用中心点当出口 | 后缘越过圆头才离开 |
| 扣转得比螺纹快 | 一圈螺纹转一整圈，八边外形每 45° 重复 | 两圈螺纹转一个边 |
| 离场穿回盘面 | 离场后不再碰撞，重力把扣拉回来 | 先沿出口离开，再受重力 |
| 螺丝自己滑出 | 扣清空就自动离场 | 必须拖，松手时才判定 |
| 杆还在套筒里就掉 | 只看了杆的中线，松手结算也没走到螺丝 | 整根金属都离开套筒，并且只在松手时掉 |
| 扣穿过卡扣 | 卡扣不挡自己这根杆上的扣 | 卡扣挡住扣；只放过自己的杆 |
| 直头离卡扣还有缝却拖不动，L 弯头又穿进卡扣 | 头的顶点半径被当成沿杆的圆，整步退回；弯头按套筒外框当孔 | 头和扣用沿杆厚度贴端面，弯管圆面贴银边，停在接触点 |
