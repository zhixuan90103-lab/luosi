# 螺丝扣

当前工程只玩螺丝。圆环、胶囊棍、衔接和关卡编辑已经不在工程里。外形尺寸在 [PARTS.md](./PARTS.md)。

## 模块

| 模块 | 职责 |
|---|---|
| `parts.ts` | 网格和尺寸。`buckleMetrics`、`BUCKLE_LENGTH_SCALE`、`screwCap`、`screwLayout` 是唯一来源 |
| `screws.ts` | 扣和螺丝怎么滑、什么时候挡住、什么时候算离开卡扣 |
| `play.ts` | 按下、拖动、松手、重力离场、把整关放进顶栏和底栏之间 |
| `camera.ts` | 设计坐标和世界坐标。视口高 10。取景用零件外框 |
| `levelio.ts` | 读 `public/levels/`。没有扣的数据时按布局生成 |

`play.ts` 不写阻挡公式。`screws.ts` 不建网格。

## 零件

一根螺丝有若干直段。直段一头是出口，另一头是死头。直螺丝的死头是八边头。L 和 U 的死头是弯。螺丝扣只在直段上，不能绕过弯。

银卡扣钉在世界里，套在死头一侧。直杆可以留在孔里。卡扣沿杆二分，停在弯折部分刚要碰到卡扣银边的地方。直螺丝没有弯，停在八边头刚要碰到的地方。卡扣不跟着杆走。整根螺丝离开后，卡扣跟着掉。

## 螺丝扣

两个方向都沿杆跟手。

- 同一段上的其他扣、死头、弯、任何银卡扣、别的螺丝，都会挡住。
- 扣的后缘完全越过杆头的圆头，才离开杆。
- 离开后先沿出口飞出，再受重力。重力是每秒 `30`。
- 绕杆的转角按螺纹走。每两圈螺纹转过八边扣的一个边。

## 螺丝

按住杆或卡扣，沿卡扣方向拖。拖的时候不掉。松手时才判定。

接触用网格的同一套尺寸：

- 套筒和把手来自 `buckleShape`，圆角和网格的 `barCorner` 相同。
- 孔的半径等于螺纹齿顶 `SHAFT_RADIUS`。直杆可以留在孔里。弯的圆面碰到套筒或把手就停，不能钻进孔里。
- 弯管和直杆的阻挡圆用光杆半径 `SHAFT_CORE`，和扫出来的管子一样粗。
- 八边头用网格的俯视外框。倒角把网格中心沿杆移了 `bevel`，阻挡跟着这圈外框走。
- 螺丝扣用网格的俯视外框。倒角把网格中心沿杆移了 `bevel`，横宽随转动变化，阻挡跟着这圈外框走。
- 死头一侧的限位是卡扣外沿再加扣的半长，不再另加空隙。
- 相贴允许。重叠超过 `0.001` 算挡住。滑动停在第一处接触，不整步退回。

自己的螺丝扣、别的螺丝、别的螺丝扣、别的卡扣都会挡住这根螺丝。松手时，杆、头、弯和还套着的扣只要有一块还在自己的任一卡扣里，就停在松手的位置。全部离开之后，螺丝、上面的扣和这些卡扣一起先沿拖动方向离开，再受重力。

## 镜头

正交相机从 +Z 看 XY。视口高度是 10 个世界单位，宽度按 390×844。进关时把螺丝外框放进顶栏和底栏之间，四周再留 24 个设计像素，并在还有空档时上移 48 像素。

## 过关

盘上没有螺丝、也没有螺丝扣时，松手弹出结算。
