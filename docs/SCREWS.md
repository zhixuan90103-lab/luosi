# 螺丝扣

当前工程只玩螺丝。圆环、胶囊棍、衔接和关卡编辑已经不在工程里。外形尺寸在 [PARTS.md](./PARTS.md)。

## 模块

| 模块 | 职责 |
|---|---|
| `parts.ts` | 网格和尺寸。中心线是 `screwSpans`。头和扣的俯视外框是 `headSilhouette`、`nutSilhouette` |
| `screws.ts` | 扣和螺丝怎么滑、什么时候挡住、点选哪一块、什么时候算离开卡扣 |
| `play.ts` | 按下、拖动、松手、把整关放进顶栏和底栏之间。不写阻挡、离场、意图、闪光或描边公式 |
| `camera.ts` | 设计坐标和世界坐标。视口高 10。取景用零件外框 |
| `fall.ts` | 离场：重力、扣的转轴、层级、出屏销毁 |
| `intent.ts` | 扣和螺丝叠在一起时，用短行程选滑轴 |
| `feedback.ts` | 撞上才闪一次，准备离场时慢慢变亮 |
| `outline.ts` | 选中件的同色屏幕描边 |
| `levelio.ts` | 读 `public/levels/`。没有扣的数据时按布局生成 |

`play.ts` 不写阻挡、离场、意图、闪光或描边公式。`screws.ts` 不建网格。改规则时改对应模块，并改这一页。

## 零件

一根螺丝有若干直段。直段一头是出口，另一头是死头。直螺丝的死头是八边头。L 和 U 的死头是弯。螺丝扣只在直段上，不能绕过弯。

要亲手拖开的零件用关卡颜色：螺丝（头和杆）和螺丝扣。银卡扣解开后自己掉，保持银色。

银卡扣钉在世界里，套在死头一侧。直杆可以留在孔里。卡扣沿杆二分，停在弯折部分刚要碰到卡扣银边的地方。直螺丝没有弯，停在八边头刚要碰到的地方。卡扣不跟着杆走。整根螺丝离开后，卡扣跟着掉。

## 螺丝扣

两个方向都沿杆跟手。

- 同一段上的其他扣、死头、弯、任何银卡扣、别的螺丝，都会挡住。
- 扣的后缘完全越过杆头的圆头，才离开杆。离开之后仍只能沿这根轴移动，不能离开轴线。松手才下落。
- 松手后的下落见下一节「离场」。扣在离场时就带上翻转。已经离开杆、手指还按着时，扣慢慢变亮。
- 绕杆的转角按螺纹走。每两圈螺纹转过八边扣的一个边。

## 螺丝

按住杆或卡扣，沿卡扣方向拖。拖的时候不掉。松手时才判定。指针每次只把新的位移投影到滑轴上，交给 `dragScrew`。

扣和螺丝叠在一起、而且两根滑轴不平行时，先不选。手指滑过大约 1% 设计宽度后，顺着扣的杆轴选扣，顺着螺丝的卡扣方向选螺丝。两根轴平行时，点在扣上仍选扣。选中后，`outline.ts` 用屏幕遮罩沿这件网格描一圈和自身同色的边，松手后淡出。描边只包含这件网格。银卡扣在摆放时已经离开螺丝组。

刚撞上、并且这一下确实移动了，才震一下，零件用自己的颜色闪大约 0.18 秒。贴着阻挡继续推不重复。离开接触大约 `0.03` 之后才能再撞一次。螺丝已经离开自己的卡扣、手指还按着时，螺丝和卡扣慢慢变亮，松手才掉。

接触、落位和点选都读同一条 `screwSpans`，不再各写一套直段和弯。

阻挡：

- 直段和弯都是半径 `SHAFT_CORE` 的管子，和扫出来的网格一样粗。
- 直段管子是桶身，可以留在卡扣孔里。碰撞半径是螺纹齿顶 `SHAFT_RADIUS`。画出来的螺旋不参与阻挡。卡扣、头、扣的网格孔是齿顶加 `THREAD_HOLE_GAP`（0.008）。
- 只有弯出桶身、并且探出孔的金属才挡住自己的卡扣。卡扣沿杆二分，停在刚要碰上的位置。直螺丝没有弯，停在八边头刚要碰上的位置。
- 套筒和把手来自 `buckleShape`，圆角是 `barCorner`。
- 八边头和螺丝扣用网格的俯视外框。倒角把中心沿杆移了 `bevel`。扣的横宽随转动变化。
- 这根螺丝上的扣，内限用同一套接触：扣的外框刚要进卡扣就停。没有卡扣的直段仍用布局里的死头内限。
- 相贴允许。重叠超过 `0.001` 算挡住。滑动停在第一处接触，不整步退回。

点选：

- 先看螺丝扣。点选框是俯视外框，沿杆放大到 1.4 倍，宽度放大到 1.2 倍。挡住别的零件仍用未放大的外框。
- 没点中扣时，杆和弯按管子半径 `SHAFT_CORE`，圆头按八边头外框，卡扣按套筒和把手的圆角条。
- 点在零件轮廓上才算选中，不用扣心或杆心的大圆。

自己的螺丝扣、别的螺丝、别的螺丝扣、别的卡扣都会挡住这根螺丝。松手时，杆、头、弯和还套着的扣只要有一块还在自己的任一卡扣里，就停在松手的位置。这一下如果方向没反，而且沿该方向再滑不超过设计宽度的 2% 就能离开自己的卡扣、也碰不到别的零件，松手就把这点距离补上，然后离场。补不动时停在松手的位置。全部离开之后，螺丝和卡扣进入「离场」，不翻转。还套在上面的扣用和单独拆下时一样的翻转。

## 离场

离开轨道之后由 `fall.ts` 负责。线速度从 0 开始，只受重力，每秒 `30`，方向是世界 −Y。不再沿出口给初速度。

螺丝扣在离场时定一根世界转轴，整段下落都绕这根轴，不拆成先绕 X 再绕 Y。轴以杆的朝外方向（死头指向开口）为底，左右随机偏最多 90°，再加一截横向随机。朝外的一侧先朝镜头（+Z）翻。初始转速大约每秒 2.4 到 4.8 弧度，下落中沿同一根轴大约每秒再加 5 到 10 弧度。

螺丝和银卡扣不翻转。

离场网格沿 +Z 抬到静止零件前面，距离是自身的旋转半径，后掉的再叠一层。正交相机不因 Z 改变大小。原点从左右或上方离开一整块屏幕，或从下方离开 `0.8`，才销毁网格。

## 镜头

正交相机从 +Z 看 XY。视口高度是 10 个世界单位，宽度按 390×844。进关时把螺丝外框放进顶栏和底栏之间，四周再留 24 个设计像素，并在还有空档时上移 48 像素。适配只用这块区域的 `FIT_FILL`（0.9），这就是画面上的正常大小。

## 过关

盘上没有螺丝、也没有螺丝扣时，松手弹出结算。
