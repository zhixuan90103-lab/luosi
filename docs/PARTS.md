# 螺丝零件

试玩画面用这些零件拼 `public/levels/`。拖动在 [SCREWS.md](./SCREWS.md)。

顶视，正交相机从 +Z 看 XY。零件是有厚度的扁片。背景 `#f6f1e8`。

代码在 `src/game/parts.ts`。中心线只写在 `screwSpans`。套筒尺寸只写在 `buckleMetrics`，缩短比例是 `BUCKLE_LENGTH_SCALE`。圆角是 `barCorner`。头和扣的俯视外框是 `headSilhouette`、`nutSilhouette`。网格、阻挡和点选都读这些，不另写一套。

| 零件 | 样子 | 尺寸 |
|---|---|---|
| 银卡扣 | 圆角套筒，中间有沿杆的孔，上下各一块圆角把手 | 宽是杆的 130%。长度按杆长的 `0.45` 再乘 `0.32 × 2/3`。把手再缩到 70%。圆角是 `barCorner`。孔半径是螺纹齿顶 `SHAFT_RADIUS`。颜色 `#c8c7c5` |
| 直螺丝 | 银色八边头、一根带螺纹的圆杆、彩色八边扣。头和扣的孔轴都沿杆 | 光杆直径 `0.14`，管子半径 `SHAFT_CORE`。螺纹齿顶是 `SHAFT_RADIUS`，只用于孔。头、扣的沿杆半长是 `screwCap`。倒角把网格中心沿杆移了 `bevel`，横宽用网格俯视外框，不使用顶点半径。顶点半径仍是扣 `0.15`、头 `0.19`。杆长 `1.55` |
| L 形螺丝 | 同一根银杆折一次。转折是圆弯。两头开口，扣只在直段上 | 中线弯半径 `0.16`，两段直杆各 `1.12`。弯和直杆同一管子半径 |
| U 形螺丝 | 同一根银杆折两次，两头开口朝同一边。扣只在两条臂上 | 弯半径 `0.16`，底边净长 `0.48`，两臂各 `1.12`。底边也是直段 |

直段是桶身，可以留在卡扣孔里。卡扣套在靠死头的直段上，不套到弯上。位置由接触测试沿杆二分：直螺丝停在八边头刚要碰上的地方，L 和 U 停在弯出桶身的金属刚要碰上的地方。外沿可以相贴，再推进去才算挡住。落位规则见 [SCREWS.md](./SCREWS.md)。
