# 螺丝零件

试玩画面用这些零件拼 `public/levels/`。拖动在 [SCREWS.md](./SCREWS.md)。

顶视，正交相机从 +Z 看 XY。零件是有厚度的扁片。背景 `#f6f1e8`。

代码在 `src/game/parts.ts`。套筒尺寸只写在 `buckleMetrics`，螺丝的缩短比例是 `BUCKLE_LENGTH_SCALE`。网格和碰撞读这一份。

| 零件 | 样子 | 尺寸 |
|---|---|---|
| 银卡扣 | 左右直切的套筒，上下各一块把手 | 宽是杆的 130%。长度按杆长的 `0.45` 再乘 `0.32 × 2/3`。把手再缩到 70%。颜色 `#c8c7c5` |
| 直螺丝 | 银色八边头、带螺纹的圆杆、彩色八边扣。头和扣的孔轴都沿杆 | 扣孔直径 `0.14`，与杆相同。头和扣沿杆的半长是 `screwCap`。顶点半径：扣 `0.15`，头 `0.19`。杆长 `1.55` |
| L 形螺丝 | 同一根银杆折一次。转折是圆弯。两头开口，扣只在直段上 | 中线弯半径 `0.16`，两段直杆各 `1.12` |
| U 形螺丝 | 同一根银杆折两次，两头开口朝同一边。扣只在两条臂上 | 弯半径 `0.16`，底边净长 `0.48`，两臂各 `1.12` |

螺丝和卡扣可以外沿相贴，网格不互相穿入。卡扣套在靠死头的一侧，不放在螺丝扣通往出口的那段杆上。
